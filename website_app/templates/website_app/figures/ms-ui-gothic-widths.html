{% comment %} MS UI Gothic advance widths — the bar chart from /blog/arpa-domain/. Font units at 1000/em, so 190 (M, W) is the widest and sets 100%. The widths are written inline rather than animated in by an IntersectionObserver, as they were when this lived in the post body: the animation was the only reason the figure needed JavaScript, and a bar chart that starts at zero width is a chart that is wrong until you scroll to it. The tracks are aria-hidden because they encode nothing the adjacent number does not already say — a screen reader gets "slash 128", not a decorative rectangle. {% endcomment %}
